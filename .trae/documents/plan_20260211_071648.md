
# 实现 AeroSmart Onboarding 页面

## 1. 后端配置修改 (Tauri/Rust)

我们需要在 `AeroSmart.toml` 中添加一个新参数 `enable_onboarding` 来控制是否显示 Onboarding 页面。

- **文件**: `panel/src-tauri/src/config.rs`
- **任务**:
  - 在 `RulesConfig` 结构体中添加 `pub enable_onboarding: bool`。
  - 在 `Default` 实现中设置默认值为 `true`。
  - 更新 `create_default_config_file_if_missing` 函数中的模板字符串，包含此新配置项及其注释。
- **目的**: 允许用户通过配置文件启用或禁用 Onboarding 流程。

## 2. 前端路由与视图 (Vue)

创建一个新的视图组件用于 Onboarding，并配置路由。

- **文件**: `panel/src/views/OnboardingView.vue` (新建)
- **任务**:
  - 创建一个全屏 Flex/Grid 布局的页面。
  - **动画效果**: 使用 Vue 的 `<Transition>` 组件或 CSS `transition` 实现淡入淡出 (Fade In/Out)。
  - **内容**:
    - **Logo**: 居中显示 AeroSmart Logo，带有弹入动画 (Scale/Fade In)。
    - **按钮**: "开始使用" (Get Started)，带有 Hover 效果。
  - **交互**: 点击按钮后，导航至主页 (`/`)。

- **文件**: `panel/src/router/index.ts`
- **任务**:
  - 添加 `/onboarding` 路由，指向 `OnboardingView.vue`。

## 3. 前端状态管理与启动逻辑 (Store/App)

在应用启动时检查配置，并决定是否跳转到 Onboarding 页面。

- **文件**: `panel/src/stores/device.ts` (或其他合适的 Store)
- **任务**:
  - 添加一个 Action 或在 `connect` 逻辑中，增加获取后端配置的能力（如果尚未实现，可能需要通过 Tauri Command 获取配置，或者简单点，通过 WebSocket 的初始握手/状态消息传递此配置）。
  - **替代方案 (推荐)**: 由于前端直接读取后端 TOML 比较麻烦，我们可以通过 Tauri Command 暴露配置，或者在 WebSocket 连接建立后的第一个消息中包含此信息。
  - **简化方案**: 鉴于目前是 WebSocket 通信，我们可以新增一个 Tauri Command `get_app_config` 来专门获取配置给前端。

- **文件**: `panel/src-tauri/src/lib.rs`
- **任务**:
  - 注册一个新的 Tauri Command `get_app_config`，返回 `AppConfig` 结构体给前端。

- **文件**: `panel/src/App.vue` 或 `panel/src/router/index.ts` (路由守卫)
- **任务**:
  - 在应用挂载 (`onMounted`) 或路由前置守卫中，调用 `get_app_config`。
  - 如果 `config.rules.enable_onboarding` 为 `true` 且用户尚未完成 Onboarding (可以使用 `localStorage` 标记作为辅助，但需求是强依赖配置文件)，则跳转到 `/onboarding`。
  - *修正*: 用户的需求是“用配置文件的参数判断是否在前端启动的时候展示”。这意味着每次启动只要配置为 true 就展示，或者配置为 true 时才检查本地状态。我们将严格遵循“配置文件决定”的逻辑。

## 实施步骤

1.  **后端**: 修改 `config.rs` 添加 `enable_onboarding` 字段。
2.  **后端**: 在 `lib.rs` 中实现并注册 `get_app_config` Tauri 命令。
3.  **前端**: 创建 `src/views/OnboardingView.vue`，实现 UI 和动画。
4.  **前端**: 更新 `src/router/index.ts` 添加路由。
5.  **前端**: 修改 `src/App.vue`，在启动时调用 `get_app_config` 并根据结果跳转。

## 验证计划

1.  修改 `AeroSmart.toml` 设置 `enable_onboarding = true`，重启应用，确认进入 Onboarding 页面。
2.  点击“开始使用”，确认能平滑过渡到主页。
3.  修改 `AeroSmart.toml` 设置 `enable_onboarding = false`，重启应用，确认直接进入主页。
