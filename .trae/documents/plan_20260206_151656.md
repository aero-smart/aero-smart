# Frontend WebSocket Implementation Plan

## 1. WebSocket API Documentation

### Connection Details
*   **URL**: `ws://localhost:3000/ws`
*   **Protocol**: JSON over WebSocket
*   **Serialization**: Rust `serde` Enum (External Tagging) -> `{"Variant": { ...fields... }}`

### Downlink (Server -> Client)
The server broadcasts telemetry data as JSON objects. The keys correspond to `SerialMessage` variants.

| Message Variant | JSON Structure Example | Target Store State |
| :--- | :--- | :--- |
| **ImuData** | `{"ImuData": {"accel_z": 9.8, "gyro_x": 0.1, "gyro_y": 0.1, "quad_w": 1.0, "quad_i": 0.0, "quad_j": 0.0, "quad_k": 0.0, "time_elapsed_ms": 1000}}` | `imu` (Need Quat->Euler conv) |
| **PitotAirspeedData** | `{"PitotAirspeedData": {"splitter_left": 12.0, "splitter_right": 12.0, "static_port": 1013.0, "time_elapsed_ms": 1000}}` | `airspeed` (Calculate velocity if needed or use raw) |
| **BatteryData** | `{"BatteryData": {"voltage_v": 12.6, "soc_percent": 95.0, "time_elapsed_ms": 1000}}` | `battery` |
| **LidarData** | `{"LidarData": {"distance_cm": 150, "signal_strength": 100, "time_elapsed_ms": 1000}}` | `lidar` |
| **BarometerData** | `{"BarometerData": {"pressure_pa": 101325, "temperature_c": 25.0, "humidity_percent": 50.0, "time_elapsed_ms": 1000}}` | `env` |
| **AcousticData** | `{"AcousticData": {"overall_spl": 80.0, "peak_frequency": 1000, "spectral_shape": [...], "turbulence_index": 0.5, "time_elapsed_ms": 1000}}` | `acoustic` |
| **AcknowledgementData** | `{"AcknowledgementData": {"time_elapsed_ms": 1000}}` | Connection Heartbeat |

### Uplink (Client -> Server)
The client sends control commands as JSON objects.

| Action | JSON Payload |
| :--- | :--- |
| **Set Throttle** | `{"ThrottleConfig": {"airspeed": <0-255>}}` |
| **Set Servo** | `{"ServoConfig": {"angle": <0-180>}}` |
| **Start System** | `{"Command": "Start"}` |
| **Stop System** | `{"Command": "Stop"}` |
| **Calibrate** | `{"Command": "Calibrate"}` |

## 2. Implementation Steps

### Step 1: Update `panel/src/stores/device.ts`
*   **Add WebSocket State**: `socket: WebSocket | null`, `reconnectTimer: any`.
*   **Implement `connect()` action**:
    *   Initialize `WebSocket`.
    *   Bind `onopen` -> `isConnected = true`.
    *   Bind `onclose`/`onerror` -> `isConnected = false`, trigger reconnection (3s delay).
    *   Bind `onmessage` -> Parse JSON, dispatch to `handleMessage()`.
*   **Implement `handleMessage(payload)`**:
    *   Switch on object keys (`ImuData`, `BatteryData`, etc.).
    *   Update reactive refs (`imu`, `battery`, `env`, etc.).
    *   **Math Helper**: Implement `quaternionToEuler(w, x, y, z)` to update `imu.attitude` (Roll/Pitch/Yaw) for the UI.
*   **Implement Control Actions**:
    *   `setThrottle(val)`: `socket.send(JSON.stringify({"ThrottleConfig": {"airspeed": val}}))`
    *   `setServo(val)`: `socket.send(JSON.stringify({"ServoConfig": {"angle": val}}))`
    *   `sendCommand(cmd)`: `socket.send(JSON.stringify({"Command": cmd}))`

### Step 2: Integrate in `App.vue`
*   Call `deviceStore.connect()` on mount to initiate the connection lifecycle.

### Step 3: Verify Data Mapping
*   Ensure `PitotAirspeedData` mapping logic handles the raw pressure vs calculated airspeed (Note: Firmware `ThrottleConfig` uses `airspeed` field for throttle value, likely mapping 0-255. `PitotAirspeedData` returns raw sensor values).
