# Service 层 WiFi 连接适配与 Onboarding 优化计划

## 1. 后端 Service 层增强 (Rust)
### 功能：网络连通性测试
- **修改文件**: `service/src/wifi.rs`
- **新增功能**: 实现 `test_connectivity` 函数。
  - 逻辑：使用 `reqwest` 请求 `https://www.bilibili.com`。
  - 返回：成功返回 200 OK，失败返回错误信息。
- **路由注册**: 在 `service/src/main.rs` 中注册 `GET /api/wifi/test`。
- **依赖检查**: 确认 `reqwest` 包含 `rustls-tls` 或 `native-tls` 以支持 HTTPS。

## 2. 前端组件开发 (Vue)
### 新增组件：虚拟键盘 (`VirtualKeyboard.vue`)
- **位置**: `panel/src/components/VirtualKeyboard.vue`
- **布局**: QWERTY 全键盘布局，包含数字行、字母行、功能键（Shift, Backspace, Enter）。
- **交互**: 支持点击按键输入字符，支持 Shift 切换大小写/符号。
- **样式**: 针对触摸屏优化的大按键设计。

### API 客户端更新
- **修改文件**: `panel/src/api/wifi.ts`
- **新增方法**: `testWifiConnection()` 调用后端的测试接口。

### 状态管理更新
- **修改文件**: `panel/src/stores/wifi.ts`
- **新增 Action**: `testConnection()` 封装 API 调用，管理测试状态（testing/success/fail）。

## 3. Onboarding 页面改造
### 页面逻辑 (`OnboardingView.vue`)
- **集成 WiFi Store**: 使用 `useWifiStore` 获取网络列表。
- **UI 重构**:
  - **列表展示**: 美化 WiFi 列表项，增加信号强度图标。
  - **密码输入**: 点击加密网络时，显示包含密码框和虚拟键盘的模态层。
  - **连接流程**: 
    1. 用户输入密码并确认。
    2. 调用 `connect` 接口。
    3. 连接成功后，自动调用 `testConnection`。
    4. **连通性验证**: 只有当 `testConnection` 返回成功（Bilibili 可达）时，才显示“已连接”并允许点击“下一步”。
- **Kiosk 优化**: 确保键盘遮挡不影响输入框可见性。

## 4. 验证计划
- **Service**: `curl localhost:3000/api/wifi/test` 验证返回。
- **Frontend**: 
  - 检查虚拟键盘输入是否正常。
  - 模拟 WiFi 连接成功但无网的情况，确认流程被阻断。
  - 确认连接成功且有网时，流程顺畅。
